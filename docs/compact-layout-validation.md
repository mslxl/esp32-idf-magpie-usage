# 紧凑卡片 A/B 验证（2026-10-27）

本轮将配置 A 改为原型 C 的单列完整边框卡片，配置 B 改为相同视觉结构的双列卡片。A/B 协议值不变。验证在现有工作树完成。

## 呈现规则

- 400×300，外边距 8px；A 卡片宽 384px，B 两列各 188px、间隔 8px。
- 完整 1px 卡框，正文距外框 4px；厂商图标与名称、粗体账号及小号套餐、窗口上分隔线、右对齐剩余额度、4px 额度条、重置和底部更新时间。
- 标题 18px，正文自适应 16/15/14px，元信息 14px。
- 原型五种图标重新转换为 16×16 单色位图。英文使用 OFL 授权 Arimo Regular/Bold；中文使用现有 Noto 子集。
- 正常卡片整体移列/翻页；窄列超高卡转全宽，超页后重复身份继续显示。保留完整数据、缺字替代和固定内存容量。
